# Prototype Lab

초기 단계 서비스 아이디어를 빠르게 기획하고, 실제 개발에 들어가기 전에 IP 리스크를
1차 스크리닝하는 사이드 프로젝트 저장소입니다. 각 아이디어는 `PLAN_*.md` 문서로
정리하고, [IP Sentinel](https://ip-sentinel-772360262201.asia-northeast3.run.app)로
자동 모니터링합니다.

> 🧪 이 저장소는 IP Sentinel 프로젝트의 시연·테스트를 위해 구성한 가상의 스타트업
> 시나리오입니다.

## 진행 중인 아이디어

| 문서 | 한 줄 소개 | 상태 |
|---|---|---|
| [PLAN_LOCKSCREEN_AD.md](./PLAN_LOCKSCREEN_AD.md) | 잠금화면 광고 SDK | 기획 |
| [PLAN_QR_ATTENDANCE.md](./PLAN_QR_ATTENDANCE.md) | QR+GPS 스마트 출석 관리 | 기획 |
| [PLAN_MEETING_ROOM.md](./PLAN_MEETING_ROOM.md) | NFC 회의실 자동 예약 확정 | 기획 |
| [PLAN_REVIEW_STAR.md](./PLAN_REVIEW_STAR.md) | 리뷰 감정 분석 기반 별점 추천 | 기획 |

## 진행 방식

각 아이디어는 기획서 커밋 시점에 IP Sentinel이 자동으로 특허 리스크를 검토하고,
GitHub 커밋 코멘트로 결과를 남깁니다. 위험도가 낮게 나온 아이디어부터 우선 개발에
착수합니다.
